# Домашние задания — курс «DevOps-инженер с нуля», Нетология

Учусь на DevOps-инженера. Здесь лежат решения по всем модулям курса: от терминала и дистрибутивов Linux до Terraform, Ansible и мониторинга.

Каждый модуль — отдельная папка, внутри папки занятий. В папке занятия: `README.md` с условием и ходом решения, скриншоты проверок, конфиги и скрипты, которые нужны для задания.

## Модули

- [01. Основы Linux](модуль-01-основы-linux/README.md) — архитектура компьютера, администрирование ИТ-систем, введение в Linux, основы терминала
- [02. Операционная система Linux](модуль-02-операционная-система-linux/README.md) — процессы, память, планировщик, дисковые и файловые системы, ядро, загрузка
- [03. Администрирование Linux](модуль-03-администрирование-linux/README.md) — дистрибутивы, пакеты, systemd, пользователи, производительность
- [04. Программирование на Bash](модуль-04-программирование-на-bash/README.md) — переменные, условия, циклы, функции, регулярные выражения, текстовые утилиты, итоговый проект
- [05. Сети и протоколы](модуль-05-сети-и-протоколы/README.md) — теория сетей, уровни L2–L4, NAT
- [06. Виртуализация](модуль-06-виртуализация/README.md) — облака, KVM и QEMU, Docker, Kubernetes
- [07. Автоматизация](модуль-07-автоматизация/README.md) — Ansible, Terraform, инфраструктура в Yandex Cloud, Git, GitLab, введение в DevOps
- [08. Мониторинг](модуль-08-мониторинг/README.md) — обзор мониторинга, Zabbix, Prometheus и Grafana
- [09. Отказоустойчивость](модуль-09-отказоустойчивость/README.md) — keepalived и VRRP, кластеризация и балансировка, резервное копирование, отказоустойчивость в облаке
- [10. Хранение и передача данных](модуль-10-хранение-и-передача-данных/README.md) — типы баз данных, Redis и Memcached, стек ELK
- [11. Базы данных](модуль-11-базы-данных/README.md) — SQL, индексы, репликация, резервное копирование БД
- [12. Безопасность](модуль-12-безопасность/README.md) — уязвимости и атаки, защита хоста и сети
- [13. Системы контроля версий](модуль-13-системы-контроля-версий/README.md) — основы Git, ветки, merge и rebase, инструменты Git
- [14. Виртуализация и контейнеризация](модуль-14-виртуализация-и-контейнеризация/README.md) — введение в виртуализацию, принципы IaaC: Vagrant и Packer
